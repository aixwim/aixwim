Industri Game Indonesia Tembus Pasar Global, Ekspor Naik 45 Persen

✍️ Tim Redaksi Aixwim🗓 2 Agustus 2026⏱ 4 menit baca🏷 Teknologi

JAKARTA, Aixwim News — Industri game Indonesia mencatat pertumbuhan ekspor sebesar 45 persen pada paruh pertama 2026, mencapai nilai US$ 180 juta. Pencapaian ini menjadikan game sebagai salah satu penyumbang devisa terbesar dari sektor ekonomi kreatif.

Kementerian Pariwisata dan Ekonomi Kreatif melaporkan terdapat 1.200 studio game aktif di Indonesia, naik dari 800 studio pada 2024. Sebanyak 40 persen di antaranya kini fokus menembus pasar ekspor dengan konten bernuansa lokal yang dikemas secara global.

Game bergenre mobile dengan budaya Nusantara menjadi primadona di pasar Asia Tenggara, Jepang, dan Amerika Latin. Beberapa judul berhasil menembus 10 juta unduhan dan masuk daftar game terlaris di berbagai negara.

Kepala Badan Ekonomi Kreatif menyebut keberhasilan ini tidak terlepas dari program inkubasi studio game dan insentif fiskal yang diberikan pemerintah. "Kami menargetkan ekspor game menembus US$ 500 juta pada 2029," ujarnya optimistis.

Pelaku industri menyoroti tantangan pendanaan tahap awal dan regenerasi talenta. Asosiasi Game Indonesia mendorong pembentukan program magang nasional yang menghubungkan 100 ribu lulusan SMK dan sarjana dengan studio game lokal.

Dengan dukungan ekosistem yang terus membaik, para pengamat meyakini Indonesia berpotensi menjadi hub game terbesar kedua di Asia Tenggara setelah Singapura dalam lima tahun ke depan.
